# Demo data

Fictional profile and postings so you can try VagaLens without your own data.
Point `paths.profile_dir` and `paths.jobs_dir` in `config.yaml` at this folder:

```yaml
paths:
  profile_dir: data/demo/profile
  jobs_dir: data/demo/jobs
```

Nothing here is real. `demo_job_1.txt` is a good fit for the demo profile and
`demo_job_2.txt` is deliberately not, so screening has both cases to separate.
